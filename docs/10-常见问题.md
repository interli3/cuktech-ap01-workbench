# 10 常见问题

## Q1：0041 能直接装 0031 的加载器吗？

不能。加载器只认 `njcuk.enstor.ap01 / 1.0.2_0031`，0041 上会被版本检查拒绝。
必须先降级。

## Q2：为什么不能直接把原版 0031 发给 0041？

因为 0041 的写入器会先把首字节取反。原版 0031 在签名拒绝分支可能提前退出，
首字节没被翻回来，落盘镜像就坏了。要发“首字节预反转”的版本。

## Q3：为什么降级要在电脑上开 443 端口？

设备下载固件走 HTTPS，URL 里写的是 `https://电脑IP/miio_fw/...`，
默认端口就是 443。脚本会在本机起一个临时 HTTPS 服务，只允许电脑自己和
目标屏幕访问，下载完就关。

## Q4：为什么屏幕要一分钟才变？

说明你用的还是旧加载器：设备每 60 秒取一次图。
换成 300 帧长连接后，设备每秒取一张，端到端通常 1～6 秒。
换加载器要刷固件，不是改配置。

## Q5：插着手机，屏幕还是“未充电”？

按顺序查：

1. 手机是否真的在充电（换线/换口）；
2. 等 10 秒，看 `run/current.json` 里 `power.ports` 有没有非零；
3. 有非零但屏幕不显示 → 传图链路问题，看 `/health`；
4. 全是 0 → 端口没输出/线不支持 PD/手机满了。

不要先怀疑解码公式。解码已经用原厂页面比对过。

## Q6：Codex 额度一直显示 `—`？

- Codex 客户端是否登录；
- 客户端升级后路径是否变了（服务会自动扫描，但接口字段可能变）；
- 手动跑 `codex.exe app-server --listen stdio://` 看有没有报错；
- 服务日志里 `statuses.codex` 是不是 `unavailable`。

## Q7：电脑重启后屏幕不动了？

显示服务是“用户登录时触发”，不是 Windows 服务。
重启后要先登录桌面，服务才会起来。这是为了 DPAPI 密钥能解开。
如果你把服务配成 Windows 服务，DeepSeek 会一直 `—`。

## Q8：两台一起跑会不会打架？

按文档隔离就不会：

- DID 不同；
- 端口不同（18765 / 18766）；
- 事务文件不同；
- 一次只写一台；
- 防火墙分别放行。

最容易翻车的是“端口写重”和“刷错 DID”，不是协议本身。

## Q9：怎么改显示端口？

改加载器里的两处 URL，再重算 CRC：

```bash
python tools/patch_firmware.py patch-url \
  --in firmware/加载器_0031_18765_硬件监测.bin \
  --out build/loader-18767-live.bin \
  --old http://192.168.1.160:18765/live.bin \
  --new http://192.168.1.160:18767/live.bin
```

新旧 URL 必须等长。改完把 `network.display_port` 也改成同一个端口。

## Q10：装加载器时报 `UnicodeEncodeError`？

因为固件文件名是中文，进 URL 时编码炸了。
`install_loader.py` 和 `downgrade_0041_to_0031.py` 已经会自动复制成
ASCII 临时文件 `ap01-ota-image.bin` 再发送。如果你自己改了脚本，
记得别把中文文件名直接拼进 URL。

## Q11：只想改 UI，不想刷机？

可以。UI 全部在电脑端用 Pillow 画，改 `tools/display_service.py` 的
`render()`，重启服务就生效，不碰设备。

改完先跑 `python tools/display_service.py --once` 看生成的 GIF，
确认 320×240、至少两帧、单帧不超过 24572 字节。

## Q12：0055 能不能降回 0031？

目前没有验证过的方案。0055 是更高版本，文件布局和签名闸门都变了，
0041 的首字节预反转经验不能直接套。不要拿它做实验。

## Q13：救机包只有这些文件够吗？

只要设备还能在线，够：

- 原厂 0031；
- 预反转 0031；
- 回原厂脚本；
- 降级脚本；
- 装加载器脚本；
- 哈希清单。

彻底离线时，任何软件包都不够，只能售后。

## Q14：能用在别的酷态科屏幕上吗？

不能直接套。本仓库只针对 `njcuk.enstor.ap01 / BL618-BL4 / 1.0.2_0031`。
型号、硬件版本、固件版本任何一个不匹配，都不要刷。

## Q15：为什么我的截图和仓库里的不一样？

仓库里的账户工作台模式截图使用示例数据（账号 A/B、假积分、假余额），
避免公开真实账户信息。你的实机显示的是你自己的数据，布局一样。

## Q16：顶部为什么没有标题？

当前布局把 `y=0..39` 留空，作为顶部留白；硬件监测模式的实际截图里这块也是空白，
标题是自绘在 `y≈40` 的。想加标题，在 `render()` 里画在 `y≈12` 即可，
不影响下面的卡片，也不需要抢原厂时钟。
改完先出预览图，再重启服务。
