## 校验

```bash
python tools/patch_firmware.py verify --dir firmware
```

输出全是 `OK` 才继续。任何一个 `FAIL` 或 `缺失`，停下来重新下载。

## 来源与改动

- 原厂 0031/0041/0055：从酷态科官方 OTA 获取，版权归酷态科；
- 降级用 0031：原厂 0031 的首字节 `0x42` 改成 `0xBD`，其余字节不动；
- `备用_0031_60秒取图.bin`：在 0031 基础上加入显示加载代码，已真机验收，每 60 秒取一次图；
- 两个「每秒」加载器：在备用版基础上改端口并换成 300 帧长连接，已真机验收；
  两个加载器之间只差端口和 4 字节 CRC，共 6 个字节。

## 预编译加载器的地址

仓库里的两个“每秒”加载器写死了电脑地址 `192.168.1.160`：

- `加载器_0031_18765_硬件监测.bin` -> `http://192.168.1.160:18765/live.bin`
- `加载器_0031_18766_账户余额.bin` -> `http://192.168.1.160:18766/live.bin`

如果你的电脑不是 `192.168.1.160`，先把电脑设成这个静态地址，或者用
`tools/patch_firmware.py patch-url` 换成等长地址。地址长度不同时，
等长替换会失败，需要重新编译加载器。

## 重要提醒

- `原厂_0055.bin` 只用于比对。本仓库没有任何脚本会把它写进设备。
- 不要改文件名后不更新 `SHA256SUMS.txt`；脚本会按清单校验。
- 不要用“另一个版本”的固件套本仓库的加载器；版本不匹配会被设备拒绝，
  或者更糟。
